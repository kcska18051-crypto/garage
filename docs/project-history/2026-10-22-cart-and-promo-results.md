# Корзина и промокод — 22 октября 2026

## Согласованный объём

Верх корзины для гостя — только добровольный вход/регистрация, без полей получателя. Данные показываются после входа; завершение заказа требует авторизации. Состояние корзины сохраняется при входе.

Демонстрационный промокод `123` даёт 10% от текущей стоимости выбранных товаров после товарных скидок, без доставки. Это прототип, не предложение реальной скидки.

## Реализация

- Общий расчёт в целых копейках для корзины, оформления, принятого заказа, кредита и коммерческого предложения. Округление распределяется между строками без расхождения итогов.
- Отдельная строка скидки 10%, старая и новая цены товаров и итоговой суммы. Ошибки пустого/неверного кода, повторное применение без накопления, изменение и удаление кода.
- Пересчёт при количестве, выборе/снятии выбора и удалении товаров. Нулевой выбор не сбрасывается при изменении количества. Сохранённая пустая корзина не заполняется заново после обновления.
- Состав, цены и условия принятого заказа фиксируются снимком и не меняются от последующих правок корзины или промокода.
- Цена по запросу не превращается в нулевую цену, бесплатный товар или основание для кредита. Доставка не включается в базу промокода.
- КП, кредит и отправка корзины перенесены в блок итогов как вторичные действия. В ссылку корзины не попадают личные данные и промокод.
- Сопутствующие товары: уникальные существующие позиции, демонстрационные варианты на 1/5/6/7/8 карточек; горизонтальная прокрутка и стрелки, одиночная карточка не растягивается. При 1–2 строках раскрыты обе, при 3+ — первая. Опции оборудования остаются отдельной механикой.
- Просмотренные товары — реальная общая история открытых карточек, без вымышленных исходных просмотров и без новой кнопки очистки.
- Наличие: выбранный регион, адреса и часы точек. Остатки конкретной точки не выдумываются; статусы «под заказ» и «нет в наличии» сохраняются.
- Новые диалоги и КП: закрытие Escape, удержание фокуса и возврат к вызвавшей кнопке.

## Проверка до публикации

- Локально: 49 тестов в 7 файлах прошли, сборка GitHub Pages успешна, 150 маршрутов. Полный локальный запуск ранее зависал без результата; он не считается успешной проверкой, итог полного набора проверяется в CI.
- В отдельном браузере проверены 360, 390, 1440 и 1920 px: промокод, ошибки, повтор, удаление, выбор, количество, обновление, вход, оформление, сохранённый итог принятого заказа, КП/кредит, отправка и импорт корзины, история просмотров, варианты сопутствующих 1/5/6/7/8, цена по запросу, пустая корзина. Ошибок JavaScript и горизонтального переполнения документа не обнаружено. Это браузерная эмуляция, не проверка на физическом телефоне.
- Контрольный пример: 46 800 ₽ → скидка 4 680 ₽ → 42 120 ₽. Товарные скидки учитываются отдельно, повторное применение не уменьшает сумму повторно.
- Исправление фиксации итогов заказа проверено регрессионным тестом сначала с падением, затем с успешным результатом. Аналогично проверена мобильная подпись для цены по запросу: «Уточняется» вместо 0 ₽.
- Статический обзор изменений не выявил новых замечаний после исправления снимка принятого заказа.

## Границы и очередь

Реальные банковские, складские и купонные интеграции не добавлены. Подбор автоэмали с двумя дочерними услугами и отдельная кнопка в шапке остаются следующей задачей. Отложенное расширение демонстрационного контента для пагинации не публиковалось.

Публикация проводится через GitHub API с проверкой ожидаемого SHA ветки `codex/homepage-prototype`. Локальные HEAD/индекс не синхронизированы с API-коммитами: нельзя отправлять локальную ветку принудительно или включать все грязные файлы; другие изменения уже опубликованы предыдущими коммитами.
