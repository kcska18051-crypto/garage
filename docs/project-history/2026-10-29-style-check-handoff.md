## Согласованные решения

- Шрифт — Manrope, локальный TTF и OFL-лицензия в `prototype/public/style-check/fonts`. В баннерах реальный Manrope встроен в SVG.
- Акции в меню: красный текст без красной рамки; остальные пункты без жирного выделения.
- Карточки товаров компактные: 5 с частью следующей на ПК, около двух на телефоне; одно изображение без точек галереи.
- Тонкая окантовка карточек сохранена. У блока «Оборудование для автосервиса» и «Хиты продаж» общей серой рамки/подложки нет. У «Новинок» и Remeza подложка сохранена.
- Цена заметная, новая и старая стоят в один ряд. Название занимает место двух строк, лишнее скрыто многоточием.
- Для примера первые три карточки каждой подборки показывают 4,9 (30), 4,8 (18), 5 (12); остальные без строки отзывов. Это демонстрационные данные, не реальные отзывы.
- Каждая товарная подборка повторяет исходные пять товаров трижды для демонстрации прокрутки.
- Корзина — компактная кнопка с иконкой: появляется при наведении/фокусе на ПК, видна на мобильном; больших кнопок не нужно.
- Избранное/сравнение уменьшены до 18px, активное состояние оранжевое без круглой рамки.
- Нижние горизонтальные ползунки скрыты; свайпы и стрелки работают.
- Стрелки товарных каруселей привязаны к середине рельса карточек симметрично слева/справа. У новостей — середина всей карточки, не картинки. Эффект glass.
- Play — оранжевый. Карточки/картинки новостей, статей, обзоров скруглены.
- Обычные секции: padding 30px 24px на ПК, 22px 12px на телефоне. Товарные блоки с подложкой — 24px/14px. Интервалы вокруг баннеров 12px/8px.
- Три ярких баннера услуг утверждены и целиком кликабельны. Название/кнопка встроены в изображение; файлы `service-manrope-v1.svg`, `rental-manrope-v1.svg`, `paint-manrope-v1.svg`.

## Последняя правка широких баннеров — важный принцип

Пользователь отверг отдельные версии для ПК и телефона. Для каждой кампании используется ОДИН SVG `banner-{season,paint,compressors,workshop}-v20.svg` без мобильного source.
Внутри холст 1400×320, вся значимая композиция в центральной зоне примерно x=450..940, y=86..234; по сторонам только фон. CSS: высота блока 160px, object-fit:cover, object-position:center. При адаптации обрезаются только свободные поля, а текст/товар остаются видимыми. Размеры существующих блоков сохранены.
Последняя реакция пользователя: «Уже лучше», затем просьба перенести все наработки в GitHub и сохранить контекст.
Не возвращать v17–v19: это отвергнутые промежуточные композиции, они локальные и не нужны в публикации.
«Рабочий пост / Всё на месте» — без точек.

Исходные прозрачные изображения сохранены в `prototype/design-sources/wide-banners/`. Генератор переносим между компьютерами: `prototype/scripts/create-wide-banners-v20.ps1`; запускать из `prototype` (PowerShell). Он встраивает исходники и шрифт в итоговые SVG. Никаких путей к временному каталогу генерации не требуется.
Герой пока использует утверждённые v4 и отдельные мобильные версии; запрет отдельных мобильных версий относится к обсуждённым четырём широким промобаннерам, не меняйте другие блоки автоматически.

## Проверка и рабочие правила

Перед публикацией: `npm run test:run`, `npm run build:pages`. Для небольших визуальных правок проверить реальную страницу в браузере, ПК и телефон (включая 360px). Проверить именно подключённые currentSrc, а не только созданные файлы. Не говорить «готово», если картинки лишь сгенерированы, но не подключены к странице. После source-изменений preview показывает новую версию только после сборки. Обновлять пользовательскую вкладку после сборки.

Пользователь не любит многократные подтверждения, затянутую работу и пустые заявления о готовности. Действовать по согласованному направлению, показывать реальные скриншоты. Не менять геометрию баннеров и не обрезать важный контент.
