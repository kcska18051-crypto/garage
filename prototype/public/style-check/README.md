# Гараж — Style Check

Самостоятельная визуальная версия главной страницы. Исходники прототипа не изменены; данные, провайдеры корзины, поиска, профиля и маршруты переиспользуются из проекта.

## Итерация V2

Светлая композиция всех трёх слайдов: текст слева, крупная фотография справа, жёлтая CTA. Убраны трапеции, диагонали, маски и наложения. Светлые сезонный баннер, рабочий пост и аренда; жёлтый в промо и услугах преимущественно выделяет действие. Тёмный консультационный блок сохранён.

Общие токены: радиусы 8/12/16 px, кнопки покупки и карусели 44 px, товарные иконки 40 px. Названия товаров 15 px на десктопе и 14 px на мобильных; цены 26/24 px, метаданные 12 px. Структура карточек и все исходные данные сохранены. Из категорий удалены декоративные стрелки, увеличены фотографии и выровнены подписи.

## Сборка и просмотр

Из `prototype/`:

```sh
npm ci
node public/style-check/build.mjs
npx tsc -p public/style-check/tsconfig.json --noEmit
npm run build:pages
npm run preview -- --host 127.0.0.1 --port 4175
```

Локальная страница: `http://127.0.0.1:4175/style-check/`. После публикации: `/garage/style-check/`.

`assets/` содержит готовые JS/CSS и логотип; обычная сборка Pages копирует их автоматически. После изменений компонентов нужно повторно выполнить `build.mjs` и закоммитить обновлённые assets. Старые `style.css` и `style-v2.css` оставлены как история предыдущей итерации и больше не загружаются.

## Проверка

При запущенном preview на порту 4175: `node public/style-check/verify.mjs`. Скрипт проверяет белый фон, отсутствие горизонтального скролла, наличие 20 карточек и 6 категорий на семи ширинах, все три слайда (21 сочетание), отсутствие скачков высоты и пересечения текста с контролами, горизонтальное выравнивание цен и кнопок (28 рядов), высоту кнопок 44 px и contain для товаров. Дополнительно проверяются компактная шапка, загрузка картинок, корзина, избранное, сравнение, слайдер, поиск, каталог, переход в товар, форма консультации и мобильное меню. Результаты — в `review/report.json`, скриншоты — в `review/`.

Полный набор существующих тестов: `npm run test:run` (425 тестов пройдены). Сборка исходного прототипа также проходит без изменений.

## Ресурсы

Палитра и логотип сохранены из предыдущего Style Check. Статус исходных изображений и фирменных материалов описан в `SOURCES.md`. Один доступный снимок товара показывается без фиктивных переключателей кадров; компонент поддерживает выбор кадра при наличии нескольких изображений. Подтверждённых фотографий реальных SKU и лицензированных веб-файлов SkodaSans в репозитории нет.

Публикация на действующую страницу не выполнялась: изменения подготовлены в отдельной ветке для визуального просмотра.
