## Уточнение геометки
После замечания пользователя старый круг с галочкой заменён жёлтой геометкой с тёмным контуром. Остриё привязано к координате. Контакты и страницы точек используют одинаковый маркер; мобильный масштаб сохраняет его заметность. Карта оформления заказа сохраняет прежний вид. Проверено: сборка, 24 теста ContactsPage/StorePage/CartCheckout, браузерные переходы и отсутствие переполнений на 320–1440 px.

## Карта без полос, чистые названия и галерея
По замечанию пользователя убраны демо-пометки на детальных страницах, демо-префиксы названий точек и строка координат. Неизвестные адрес/график обозначены «уточняется», фактические сведения не выдуманы. Новые ссылки ведут на /contacts/yaroslavl, /contacts/vologda, /contacts/cherepovets без служебных параметров; старые store/pickup/service открываются для совместимости. Для новых адресов добавлены HTML-входы Pages.

Галерея: три компактных квадратных фото, временно одинаковых по прямому указанию пользователя. Каждое открывается в просмотрщике; есть переключение, Escape, возврат фокуса и блокировка прокрутки страницы через существующий CartDialog.

Карта: SVG-область на страницах контактов рассчитывается по фактическому размеру контейнера через ResizeObserver. Количество тайлов подбирается по ширине, поэтому подложка покрывает весь блок, без серой полосы и искажения географии. Выбор координат оформления заказа сохраняет прежние размеры области.

Браузером проверены четыре страницы на 1440/768/390/320 px: соотношение области карты совпадает с блоком, тайлы покрывают всю ширину, все три фото открываются и переключаются, Escape возвращает фокус, переполнений нет. Добавлен тест галереи на городском URL, актуализированы проверки названий контактных точек.
