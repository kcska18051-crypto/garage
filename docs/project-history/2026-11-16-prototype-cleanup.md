# Сокращение демонстрационных страниц

Согласовано пользователем: удалить пять черновых направлений каталога, 147 упрощённых детальных страниц товаров и шесть повторных страниц подборок. Данные/карточки сохранить для демонстрации списков, корзины и сравнения. Сохранить полноценную карточку Remeza и две модификации. Юридические страницы и /style-check не входят в это удаление.

План: единая политика доступных переходов; удалить маршруты и статические exports черновиков; убрать переходы из всех поверхностей; шесть подборок перевести на URL-фильтры; проверить покупку и листинги, отсутствие удалённых ссылок, сборку и публикацию. Старые удалённые адреса показывают 404, не другую карточку. Данные и фотографии сайта не удаляются.

## Выполнено

- Из static publication исключены 5 черновых направлений, 147 упрощённых PDP и 6 дочерних URL; осталось 114 публикуемых URL (было 272). Удалён старый шаблон DemoProduct и неиспользуемые стили.
- Доступны только PDP Remeza и две модификации. Остальные товары остаются данными для списков/покупки, но изображения и названия не ведут на черновые страницы.
- Общий DemoLink применяет единую политику переходов к динамическим ссылкам всех поверхностей; внешний вид статичных названий сохранён, они не попадают в Tab-порядок и не показывают интерактивный курсор.
- Быстрые пункты шапки тоже статичны; старые алиасы /catalog/lifting, /catalog/body, /catalog/paint возвращают в общий каталог.
- Подборки винтовых компрессоров используют query-фильтры receiver/drive/configuration. Для демонстрационных данных добавлен признак комплектации и видимый фильтр; все шесть подборок дают непустое подмножество и имеют сбрасываемые чипы.
- Подсказки поиска по товарам без дизайна детали ведут к результатам поиска с названием товара, в том числе при выборе клавиатурой. Запрос цены в сравнении открывает консультацию вместо удалённого PDP.
- Юридические страницы, /style-check, готовые услуги/материалы/акции/кабинет не удалялись. Главная сетка и padding не изменялись.

## Проверки

- Production build: 114 URL, успешно.
- Браузерный обход всех 114 публикуемых URL с демовходом: нет ссылок на удалённые страницы и ошибок JavaScript.
- Проверены 404 удалённых адресов, работа query-подборки и её чипа, отсутствие переполнения на 1440/390 px в главной, каталоге, листинге, корзине и сравнении.
- Актуальный набор motion/services E2E: 16/16 прошли.
- Обновлены прежние тестовые контракты открытия удалённых страниц. Новые проверки подтверждают сохранение покупки из списка и отсутствие URL черновых карточек.
- Итоговый полный модульный прогон и статус публикации смотреть в GitHub Actions для коммита этой заметки; не использовать промежуточные логи как подтверждение итоговой публикации.
