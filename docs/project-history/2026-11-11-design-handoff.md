## Обязательные ориентиры
Главная — визуальный канон. Главную и каталог без отдельного запроса не переделывать. Белый фон, Manrope, тонкие границы, жёлтые навигационные акценты, тёплые жёлтые переходы/обращения, красная покупка/отправка форм. Это полноценный дизайн, не раскрашивание прототипа.

Компактность — приоритет пользователя. Карточки материалов/акций около 314 px шириной и 300 px высотой; фото карточек 120 px. Детальные фото обычно 180–240 px, ремонт/сервис до 280 px на компьютере и 180 px на телефоне. Заголовок и подзаголовок вместе, на одной левой оси. Не добавлять черновые надзаголовки, технические пояснения и повторяющиеся блоки. Проверять все места использования компонента: три колонки оставались в связанных материалах после исправления списка.

### Как начать завтра

Источником актуального состояния служит ветка GitHub, а не старые временные папки или локальная копия на другом компьютере. Если репозиторий уже есть, сначала проверить незакоммиченные изменения. Не сбрасывать и не перезаписывать их. Для чистой рабочей копии:

```powershell
git status
git fetch origin
git switch codex/homepage-prototype
git pull --ff-only origin codex/homepage-prototype
cd prototype
npm ci
npm run dev -- --host 127.0.0.1
```

Если репозитория ещё нет:

```powershell
git clone --branch codex/homepage-prototype https://github.com/kcska18051-crypto/garage.git
cd garage/prototype
npm ci
npm run dev -- --host 127.0.0.1
```

Прочитать эту заметку и `2026-11-11-brands-design.md`, затем сверить актуальный код и последние коммиты. Не возвращать оформление из старого прототипа. Последний запрос пользователя — сохранить итоговый коммит и завершить работу на сегодня.

Предлагаемый следующий комплект: результаты поиска и сравнение товаров. Далее корзина и оформление заказа, новинки, личный кабинет. Начинать только после следующего поручения пользователя. Доставка, оплата и гарантия уже оформлены ранее.

На этом компьютере вспомогательные скриншоты и одноразовые браузерные сценарии остаются локальными и не включаются в итоговый коммит. Все исходники сайта, используемые изображения и заметки переданы через GitHub.
