# Карточка товара: порядок, богатое описание, больше сопутствующих

Пользователь попросил исправить сортировку вкладок, показать таблицы/фотографии в описании и больше компактных сопутствующих товаров.

- Единый порядок навигации и содержимого: Описание → Характеристики → Комплектация → Опции → Сопутствующие товары → Видео → Документы → Отзывы → Вопросы → Доставка и оплата → Сервис и гарантия.
- ProductSectionNav отслеживает текущий раздел при ручной прокрутке и нажатии; активная вкладка имеет aria-current и жёлтое подчёркивание. На телефоне нужный пункт прокручивается только по горизонтали, без прыжка страницы.
- ProductDescription: обычный текст/подзаголовки/список, две существующие фотографии оборудования высотой 180 px (130 на телефоне), пример доступной таблицы модификаций из уже имеющихся предложений Remeza. Выбранная модификация выделена. Таблица на узком экране прокручивается внутри области с фокусом, не расширяет страницу.
- Сопутствующие: четыре компактные карточки в ряд на десктопе и две на телефоне. Сначала четыре, по «Показать ещё 4» — все восемь существующих демонстрационных позиций; «Свернуть» возвращает исходный вид. Цены, артикулы и покупка сохранены, уведомление о добавлении находится внутри этого блока.
- Для временных изображений аксессуаров использованы компактные предметные SVG; существующая фотография фильтра сохранена. Это демонстрация расширенной выкладки, совместимость позиций с товаром не подтверждается автоматически.
- Общие отступы главной, услуги, профиль и предыдущие изменения телефонов не затрагивались.

Проверки: production build; 14 unit-тестов деталей/порядка/таблицы/модификации/добавления; дополнительно прежние сценарии SKU; 3 новых E2E на 320/390/1440 px — навигация и ручная прокрутка, таблица/фото, 4→8 позиций, количество колонок, корзина и отсутствие горизонтального переполнения. Скриншоты описания и раскрытой выкладки просмотрены. Полный unit-набор/публикация — GitHub Actions.
