# Оформление заявки на услугу из личного кабинета

Пользователь подтвердил модель: **заявка с последующим согласованием стоимости и сроков**, без оплаты при оформлении.

Ранее формы отдельных услуг уже сохраняли обращения в кабинет, но кнопка «Новая заявка» в кабинете лишь уводила в общий раздел услуг. Теперь она открывает `/profile/services/new` — отдельный сценарий выбора направления и услуги/оборудования.

Путь: «Заявки на услуги» → «Новая заявка» → ремонт / подбор автоэмали / аренда → конкретная позиция → «Заполнить заявку» → существующая форма → номер и статус → «Посмотреть заявку в личном кабинете» → точная карточка обращения. Контакты подставляются из текущего профиля, их можно изменить. При смене направления старая выбранная позиция сбрасывается.

Повторно используется общая логика ServiceRequestDialog и serviceRequests: заявки с публичных страниц и из кабинета находятся в одной истории, сохраняют принадлежность подтверждённому телефону, защиту от дубликатов и восстановление после перезагрузки. Гостевой вход на новый маршрут требует авторизации. Старые публичные формы не изменены по поведению.

В деталях новой заявки отдельно обозначено, что стоимость и сроки требуют согласования. Аренда не объявляется подтверждённой бронью. Реального обращения к менеджеру/платёжной системе не добавлено: прежняя демонстрационная модель хранения в браузере сохраняется.

Проверено: 26 тестов форм/сохранения/связи с кабинетом, включая новые проверки входа в сценарий, сброса выбора, автозаполнения и полного пути ремонта; production build; браузерное создание всех трёх типов с открытием и перезагрузкой точной карточки. Проверены 390 и 320 px без переполнения.
