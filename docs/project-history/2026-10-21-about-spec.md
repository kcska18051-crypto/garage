# «О компании»: согласованное ТЗ и план

Пользователь согласовала «Делаем». Это отдельное разрешение на замену временной страницы /about; прежняя фиксация её текста/дизайна больше не применяется к этому этапу. Меню каталога не начинать.

## Требования

1. Крошки, H1 «О компании», связный рыбный вводный текст о магазине оборудования, инструмента и материалов для мастерских; компактное место под фото магазина/команды, не гигантский hero.
2. «Компания в цифрах»: XX лет на рынке, X городов, XX XXX товаров. Именно заменяемые маски, не конкретные выдуманные факты.
3. «Наши преимущества»: 4–6 коротких демотезисов с пояснениями; пример содержания, без неподтверждённых гарантий, сроков и дилерства.
4. «Бренды и производители»: существующий справочник, текстовые wordmark, реальные доступные переходы и «Все бренды». Реальные бренд-логотипы не генерировать.
5. «География присутствия»: Ярославль, Вологда, Череповец из общего массива точек, явно демогеография. Компактные переходы в Контакты с выбранным городом, не копия контактной страницы.
6. «Наши новости»: три записи из общих данных новостей с согласованными названием, датой, анонсом и detail URL; «Все новости».
7. «Наши соцсети»: некликабельные оформленные места «Ссылка будет добавлена», без выдуманных аккаунтов, href="#" и пустых действий.
8. «Реквизиты»: юридическое наименование, ИНН, КПП, ОГРН, юридический адрес и банковские поля с масками/«Будет заполнено». Нет чужих реквизитов и неработающей кнопки скачивания.

Сверху ненавязчивое уведомление о демонстрационном характере всего наполнения. Готовые шапка/подвал и центрированный контейнер сохраняются. Mobile: тот же порядок, сетки цифр/преимуществ/брендов без обязательного горизонтального скролла, удобные touch-ссылки. Никаких новых форм, команды или достижений.

## Решения в рамках ТЗ

- Ограниченная переработка существующего AboutPage.tsx/CSS, без новых подсистем и зависимостей. Локальная конфигурация aboutData хранит только рыбные тексты/маски; бренды/города/новости импортируются из общих источников.
- Для Remeza — существующий PDP бренда; остальные представленные бренды ведут в существующий каталог брендов с их названием в query поиска. Общий BrandsDirectory читает этот query, не создаются фиктивные brand-detail.
- Ссылка города использует /contacts?city=...; ContactsPage восстанавливает только допустимый город и синхронизирует вкладку, список, карту и регион. Изменяется только URL-адаптер, не дизайн контактов.
- Принятый пользователем текущий охват акций больше не блокер пакета 12. Другие ветки каталога — будущий отдельный scope.
