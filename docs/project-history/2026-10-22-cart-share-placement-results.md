# «Поделиться корзиной» в верхней строке товаров

## Утверждённая правка

По переданному указанию пользователя22октября действие share перенесено из правого блока итогов в верхнюю панель товарного блока, справа от «Выбрать всё» и счётчика выбора. Старая кнопка справа убрана, дублей нет. КП и кредит остаются справа. Удаление выбранных не добавлялось: такого действия ранее не было.

Используется тот же CartTools и ShareCartDialog, с разделением placement toolbar/summary. В toolbar выводится только компактная иконка+текст share, справа — только КП/кредит. Обработчик, создание URL по выбранным строкам, структура payload, варианты/распределения опций, копирование и открытие общей корзины не изменены. На360/390 кнопка переносится внутри панели на вторую строку с сохранением подписи, без пересечения с чекбоксом. Бонусы и другие поля референса не копировались.

## Границы

Меняются только точка размещения share и её адаптивная вёрстка. ShareCartDialog, sharedCartData, CommerceState, параметры/логика ссылок не меняются. Пользовательские данные и окна сохраняются; закрываются только собственные browser contexts/popups в finally.
