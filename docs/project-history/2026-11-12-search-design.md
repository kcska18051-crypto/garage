## Концепция
Выдача для выбора товара вместо бесконечной ленты прототипа: компактный заголовок и запрос, форма уточнения, разделы с количеством совпадений, фильтры слева, сортировка и товары. Без декоративного баннера: основное внимание — результатам.
Белый фон, Manrope, жёлтый поиск/навигация, тёплые переходы в каталог, красная покупка. Применены существующие CatalogProductCard; четыре карточки в ряд на широком экране, три на промежуточном, две на планшете и телефоне. Фото 120/100 px, названия до двух строк. Статусы магазинов показываются в пределах трёх.

## Поведение
Сохраняется прежний findSearchProducts: названия, бренды, артикулы, стабильные ID и существующие товарные ссылки. Новый адаптер searchResults.ts переводит результаты общего реестра в формат согласованных карточек, не ограничивая поиск только компрессорным каталогом.
Раздел, наличие, бренд, цена, сортировка и страница хранятся в URL; при изменении параметров q сохраняется. По 12 товаров на страницу, номера в центре. Смена страницы возвращает фокус к результатам. При изменении запроса прежние фильтры сбрасываются.
На телефоне фильтры раскрываются внутри страницы, без дополнительного попапа. Пустой запрос предлагает начать поиск; запрос без совпадений — примеры и каталог; пустая фильтрация — сброс параметров с сохранением запроса.
CatalogProductCard получил два необязательных параметра только для поиска: mediaFallback и quoteHref. Без этих параметров прежнее поведение карточек сохраняется. Запрос цены в поиске ведёт в существующий товар. Неизвестные фото не подменяются случайными: вместо серой геометрической заглушки — нейтральная пиктограмма с подписью «Фото уточняется». Реальные изображения используются там, где они есть в имеющихся активах.
