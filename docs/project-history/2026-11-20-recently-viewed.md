# 2026-11-20 — Вы недавно смотрели

Внизу детальной карточки добавлен блок «Вы недавно смотрели» из реальной истории браузера. Карточки используют существующий дизайн каталога: до четырёх в видимой области на десктопе, горизонтальная лента на мобильном. Отображаются только сохранённые товары с готовыми детальными страницами, без заполнения выдуманными просмотрами; при первом просмотре показан текущий товар.

Выбранная комплектация записывается в историю по ID предложения, включая переключение варианта внутри карточки. Последний просмотр первый, повторов нет. История общая с корзиной и ЛК, сохраняется после перезагрузки. Существующие действия карточек работают: переход, корзина, избранное, сравнение.

Проверки: production build; 21 unit-тест (карточка товара, история, разделы корзины); 2 браузерных сценария на 320 и 1440 — последовательность просмотров, повторное открытие, сохранение, корзина, локальная прокрутка без переполнения страницы. Скриншоты просмотрены.
