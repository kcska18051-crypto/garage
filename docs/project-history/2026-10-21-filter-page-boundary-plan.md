# Закрепление фильтра до конца основной области каталога

Уточнённое требование пользователя: не отключать фильтр на конце товарной сетки. Он сохраняется под фактической шапкой через текст категории до приближения footer; пустая/суженная выдача не растягивается фиктивными товарами/пустыми рядами. Mobile drawer без изменений. Предыдущий `c582e2f` исправил URL-parser, но сохранил прежнюю, теперь пересмотренную границу grid.

## Решение

Общий ProductListing: slot сохраняет только реальный размер колонки, а ограниченно фиксируемый sidebar использует closest main как нижнюю границу. При приближении footer доступная высота уменьшается с внутренним scroll и доступным reset; когда даже минимальная рабочая высота не помещается, колонка уходит с основной областью, не накрывая footer. Верхние границы и ширина берутся из реальной геометрии, изменения шапки/resize/контента отслеживаются. Текст после сетки остаётся справа от занятой фильтром колонки и не перекрывается. На mobile слот скрыт, inline-фиксация очищается.
