Самостоятельная визуальная версия главной. Изменения ограничены `prototype/public/style-check/`; исходный интерактивный прототип, его данные и бизнес-логика сохранены.

## Визуальная система

- Белая основа #FFFFFF; локальные поверхности #F5F6F7; текст #171717 / #62666B; фирменный жёлтый #FFCC00 для действий; красный #C92F29 для акций. Радиусы 8/12/16 px, шаг отступов 4 px.
- Шапка: единые иконки и кликабельные области услуг, профиля, сравнения, избранного и корзины; отдельное действие подбора автоэмали без разделительной линии.
- Главный баннер: без надзаголовка; фиксированные позиции заголовка, описания и CTA; одна группа «назад / номер / вперёд», свайп и прежнее автопереключение.
- Категории: крупные светло-серые карточки, названия сверху, предметные фотографии contain. Три колонки на десктопе, две на мобильном.
- Карточки: статусы → изображение → название → существующие параметры → наличие → цена → покупка. Красная акция, жёлтый хит, контурная новинка. Цена и кнопка выровнены. Напряжение и мощность выводятся из существующего реестра; отсутствующие параметры не выдумываются.
- Хиты продаж: одна светло-серая зона с белыми карточками. УТП: четыре равновысокие карточки с исходными текстами и линейными иконками. Услуги, компания, материалы и тёмная финальная консультация сохраняют расположение.

## Настройка промобаннеров

`src/promoDesign.ts` задаёт для каждого ID существующего баннера фон (`white/subtle/yellow/graphite`), текст (`dark/light`), изображение, положение, fit, дополнительное изображение, вариант CTA (`yellow/outline/dark`) и композицию (`editorial/equipment/photographic`). Меняется только объект данных, разметка `PromoBanner.tsx` остаётся общей. Для графитового фона следует выбирать светлый текст; для остальных — тёмный. Смешивание предметных фото отключается на графитовом фоне, чтобы оборудование оставалось видимым. Административной панели нет.

## Сборка и просмотр

Из `prototype/`:

```sh
npm ci
node public/style-check/build.mjs
npx tsc -p public/style-check/tsconfig.json --noEmit
npm run build:pages
npm run preview -- --host 127.0.0.1 --port 4175
```

Локально: `http://127.0.0.1:4175/style-check/?v=3`. После публикации: `/garage/style-check/`.

`assets/` содержит готовые JS/CSS и логотип. Обычная сборка Pages копирует их автоматически. После изменений компонентов необходимо повторить `build.mjs` и включить новые assets в коммит. Старые `style.css` и `style-v2.css` больше не загружаются.

## Проверки

```sh
node public/style-check/verify.mjs
npx vitest run --config public/style-check/test.config.ts --maxWorkers=2
npm run test:run -- --maxWorkers=2
```

Браузерная проверка на порту 4175: 1920/1440/1366/1280/1024/768/390/375 px; белый фон; отсутствие горизонтального скролла; 20 товаров и 6 категорий; 24 сочетания слайда и ширины с фиксированными текстовыми/CTA-позициями; 32 товарных ряда с выровненными ценами и кнопками 44 px; загрузка фото и прежние пользовательские сценарии. Проверки конфигурации промо запускаются отдельно, чтобы копия исходников в `dist/` не выполнялась повторно как тесты.

Для сравнения с оригиналом запустить второй preview:

```sh
node node_modules/vite/bin/vite.js preview --host 127.0.0.1 --port 4176 --base=/garage/
node public/style-check/compare-prototype.mjs
```

Сравниваются отрисованные страницы: последовательность 18 заголовков, 20 товаров с ценами/наличием, 6 категорий, 8 брендов, 4 промо, 3 услуги, все 51 исходное направление ссылок, новости, статьи и обзоры. Отчёты — `review/report.json` и `review/prototype-comparison.json`; скриншоты — `review/`.

## Ограничения ресурсов

Логотип и палитра сохранены из ресурсов проекта. Предметные фото иллюстрируют тип оборудования, а не подтверждённые SKU; см. `SOURCES.md`. Лицензированных веб-файлов SkodaSans и отдельных файлов логотипов товарных брендов нет: сохраняются согласованный запасной шрифт и существующие названия брендов. Новые фотографии и логотипы не подменяются случайными ресурсами. Прежние скриншоты Hoff не приложены в этом чате; использован только описанный пользователем принцип серой зоны с белыми карточками.

Публичная страница не обновлялась; результат находится в отдельной ветке и черновике PR.
