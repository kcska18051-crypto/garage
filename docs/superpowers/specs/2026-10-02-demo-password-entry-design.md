# Демонстрационный вход по паролю

## Решение

В публичном прототипе вкладка «По паролю» сохраняет поля будущей формы, но при включённом централизованном demo-флаге не проверяет и не сохраняет телефон или пароль. Нажатие «Войти» завершает существующий сценарий авторизации через `onComplete`, поэтому переход в `/profile` и возврат в checkout продолжают определяться уже существующим `returnTo`.

Рядом с формой показывается явная подсказка: «Демонстрационный режим: нажмите „Войти“, чтобы открыть личный кабинет. Заполнять поля не нужно».

## Ограничения

- Изменение относится только к методу «По паролю».
- SMS, регистрация и восстановление не меняются.
- Пароли не сохраняются и backend не подключается.
- Возможность отключается одним флагом `DEMO_PASSWORD_ENTRY_ENABLED`.
- Это временное поведение публичного прототипа, а не требование к рабочей авторизации.

## Проверки

- Пустой вход из кнопки «Профиль» открывает личный кабинет.
- Пустой вход из checkout сохраняет checkout как точку возврата.
- Подсказка видна только во вкладке «По паролю».
- Сценарий SMS по-прежнему требует номер и код.
- Проверки выполняются на desktop и mobile.
