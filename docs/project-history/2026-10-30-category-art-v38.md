# Категории с интегрированными подписями V38

Пользователь выбрал оба направления сравнительного листа и потребовал текст внутри изображения. Сгенерированы built-in imagegen 10 самостоятельных законченных изображений (5 calm + 5 expressive). Полные названия: Материалы для кузовного ремонта; Инструмент; Материалы для мойки и детейлинга; Подъёмники; Компрессоры. Повтор Инструмента не дублировался, шестая категория пока не определена пользователем

На Style Check подключены WebP, полные PNG исходники и промпты лежат в artifacts/category-cards-v38. Категории изолированы от общего каталога в categoryArtCards; реальные существующие пути body/tools/lifting/compressor-equipment сохранены. Для мойки пока используется поиск каталога q=мойка, отдельной категории в данных прототипа нет

Пять карточек на desktop, две колонки на mobile ради читаемости встроенных длинных названий. Переключатель сохранён. Видимого HTML дублирования подписи нет, доступное название ссылки сохранено

Дополнительная правка преимуществ: убрана лишняя min-height, одинаковый padding top/bottom18px на desktop и14px на mobile. На desktop заголовки занимают общую зону44px, чтобы низ был ровным. Итоговая высота обоих вариантов130px при1440px
