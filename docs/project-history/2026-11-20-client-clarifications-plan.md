# Уточнения клиента — план 20.11.2026

Источник: https://docs.google.com/document/d/1WmpOqyQe_lPgZ-IKfCPK2RccBFtrg2D8we98yCMhk18/edit
Базовый коммит: 436a0b3. Новые пояснения имеют приоритет над исходным списком. «Хочу дешевле» отменён.

Независимые блоки: (1) характеристики плитки до 7, fallback-анонс без бренда, нейтральный фильтр с жёлтой пиктограммой, мобильная окантовка; (2) автозаполнение имени/email/телефона авторизованного профиля во всех формах с сохранением ручных правок; (3) коммерческая шапка КП, изображение, контакты, ссылки, дисклеймер, печать; (4) карусель отзывов новые первыми и раскрываемая иерархия вопросов с рабочими формами; (5) видимые подписи действий товара; (6) мобильный Remeza без фото/CTA, сворачиваемое описание, логотип, карусель, визуальные секции; (7) профиль в двух долях нижней навигации вместо Подбора, гостю Войти; (8) видимый город вне бургера; (9) компактное окно телефонов с фиксированным крестиком; (10) пропорциональные изображения популярных категорий.

Истинный сертификат дилера и вводные визуала сервисного центра/подбора автоэмали ожидают пользователя. Фиктивные документы и обещания не добавлять. Встреча по 1С в декабре — организационная заметка, не новая функция.

Визуальная основа: существующая главная, Manrope, белый/чистый нейтральный, #FFCC00, #242424, красный покупки #C92F29; компактность, без цветной рамки у залитых кнопок. Padding главной не менять.

Проверки: scoped unit, production build, общая интеграция и браузер 320/390/767/1440 плюс короткие экраны, клавиатура/reduced motion, скриншоты, отсутствие горизонтального переполнения. После этого публикация GitHub Pages и публичная проверка. Все выполненные пункты и остатки зафиксировать в handoff.
