# «О компании» — реализация и проверка 21.10.2026

Основание: [согласованное ТЗ и порядок работ](2026-10-21-about-spec.md). Изменяется именно /about; ранее действовавший запрет снят пользователем для этой структуры. Меню каталога, шапка и подвал не переделывались.

## Реализовано

Восемь блоков по утверждённому порядку: вводный текст и компактное фото-место, цифры-маски, четыре преимущества, бренды, география, три новости, соцсети, реквизиты. Всё наполнение явно демонстрационное. Нет вымышленных цифр/аккаунтов/реквизитов, обещаний сроков и статуса дилера, фиктивных ссылок соцсетей или неработающего скачивания.

Бренды берутся из общего `brandDirectory`: Remeza → имеющаяся деталка, остальные → общий справочник с поисковым query. География берётся из `contactPoints`: ссылки открывают существующие Контакты с нужным городом, вкладкой, списком и картой; query восстанавливается после reload. Новости используют общие title/dateLabel/summary/slug из `materialsData`, отдельные копии не создавались.
