## Как устроена реализация

Основной файл: prototype/src/pages/ServicesPages.tsx.
Стили:
- ServiceCenterPage.css — общий вид обновлённых страниц ремонта.
- CompressorRepairPage.css — навигация по типам компрессора.
- ScrewRepairPage.css — шаблон детальной страницы ремонта.

В ServicesPages.tsx компонент ApprovedCompressorRepairPage используется для screw и piston. Заголовок, описание и ServiceRequest передаются параметрами. Несмотря на старые имена CSS-классов screw-repair-*, оформление общее для этих двух страниц. Для diesel пока остаётся прежний ServiceDetail — не считать его обновлённым.

Форма: prototype/src/features/services/ServiceRequestDialog.tsx. На страницах ремонта открывается kind=repair с правильным itemId (screw/piston), полями имени, телефона, модели, неисправности и необязательного фото. Реальная серверная отправка не подключалась. Два чекбокса согласия сейчас реализованы для kind=paint; в ремонте их наличие не добавлялось. Не утверждать обратное.
