# Лёгкая анимация интерфейса

Пользователь согласовал спокойные анимации окон, меню, раскрытий, полей заявки и подтверждений. Не добавлялись появления секций при прокрутке, подъём карточек или увеличение кнопок.

- Общий файл `src/styles/motion.css`: окна 180 мс / 8 px, выпадающие меню и сообщения 160 мс / 4 px, мобильные панели 180 мс / 12 px. Цвета, сетка и padding страниц не изменены.
- `useAnimatedClose` выполняет явное закрытие окна за 140 мс, сохраняет параметры callback, игнорирует повторное закрытие и отменяет таймер при размонтировании. Действия с переходом на другую страницу не ждут анимацию. Для неподдерживаемого Web Animations API и `prefers-reduced-motion` закрытие немедленное.
- Подключено к общим окнам входа, связи, ЛК, города, каталога, мобильного меню/фильтров, корзины/ссылки корзины, точки получения, коммерческого предложения и галереи. Встроенная форма заявки не трактуется как модальный диалог.
- Формы заявки и уведомления мягко появляются. Счётчики в шапке и мобильной панели получают один небольшой акцент при изменении.
- Раскрытие native details использует плавную высоту при поддержке interpolate-size; без поддержки остаётся рабочее стандартное поведение.
- В диалогах ЛК обеспечены Escape, удержание Tab, блокировка прокрутки и возврат фокуса. В мобильных фильтрах восстановлен фокус, включая dev StrictMode.
- При уменьшении движения новые анимации/переходы отключены, задержки закрытия нет.

Проверки: 4 теста hook (однократное закрытие, аргументы, уменьшение движения, отмена при навигации и исключение inline-форм); адресные прогоны авторизации, ЛК и корзины; production build. Браузерный проход 8 типов окон в двух режимах движения (16 случаев), раскрытие фильтра в обоих режимах с восстановлением геометрии и без переполнения. Добавлены 7 E2E-проверок анимации, фокуса, клавиатуры, счётчика и мобильного фильтра — проходят. Полный модульный набор выполняется при публикации GitHub Pages.
