# Интерактивный прототип «Гараж»

В этой папке хранится весь код и связанные материалы интерактивного прототипа интернет-магазина «Гараж».

## Принципы прототипа

- нейтральная айдентика без привязки к будущему брендбуку;
- серые геометрические плейсхолдеры вместо финальной графики;
- интерактивные переходы между прототипируемыми страницами и состояниями;
- самостоятельные адаптивные решения для десктопа, ноутбука, планшета и мобильного устройства;
- возможность развивать прототип в основу будущего дизайна и фронтенд-вёрстки.

Готовые модули — адаптивная главная страница, общая оболочка и связанный каталог с двумя уровнями категорий.

## Локальный запуск

```powershell
npm install
npm run dev
```

Проверки:

```powershell
npm run test:run
npm run build
npm run test:e2e
```

`npm run build` включает TypeScript-проверку. Отдельный lint-скрипт в прототипе пока не настроен.

## Реализованные маршруты

Главная страница полностью интерактивна. Каталожная цепочка доступна по маршрутам:

- `/catalog` — корень каталога;
- `/catalog/compressor-equipment` — категория первого уровня с сокращённым фильтром;
- `/catalog/compressor-equipment/screw-compressors` — категория второго уровня с тегами и максимальным фильтром;
- `/catalog/compressor-equipment/oil-free-compressors` — тот же шаблон без необязательного блока тегов.

Фильтры, сортировка, вид выдачи, пагинация и готовые подборки сохраняются в URL. Остальные основные переходы ведут на нейтральные страницы-заглушки; неизвестный адрес открывает страницу 404.

## Контрольные разрешения

Визуальная проверка проводится на ширинах 1920, 1440, 1280, 1024, 768, 390 и 360 пикселей. Начиная с 1680 пикселей используется широкий контейнер 1536 пикселей. Скриншоты локальной проверки сохраняются в `artifacts/` и не входят в исходный код.
