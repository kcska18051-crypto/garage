# Гараж — готовые растровые баннеры V22

30 октября 2026. Работа выполняется локально; GitHub и опубликованная версия не обновлялись.

## Согласованное решение

После замеров пользователь выбрал: **сохранить один файл и все размеры; принять узкую центральную композицию на ПК**. Поэтому у широких баннеров основная композиция находится в безопасном центре, а по бокам — продолжение фона. Отдельных мобильных файлов нет.

Дополнительное правило пользователя: без завершающих точек в рекламных текстах; CTA без жирной окантовки. Эти правки внесены непосредственно в растровые изображения. Разделители существующих демонстрационных условий акций сохранены.

## Принцип реализации

Один баннер = один готовый WebP. В самом изображении находятся фон, оборудование, заголовок, подзаголовок, CTA, свет и тени. Разметка баннера — только ссылка с одним img. CSS задаёт размеры, object-fit/object-position, скругление внешнего контейнера и доступный фокус; не собирает рекламный макет.

Старый CampaignArtwork удалён из используемого кода. Индекс больше не подключает V21: используется campaigns-raster-v22.css и CampaignRaster.tsx. Видимых HTML-заголовков и CSS-кнопок внутри рекламных баннеров нет. Полные описания сохранены в alt, ссылки не переопределяют их укороченным aria-label.

Существующий интерактивный блок консультации — форма с двумя действиями — сохранён отдельно; он не заменён рекламным изображением.

Все 13 файлов созданы через встроенный image_gen на основе ранее подготовленной предметной графики проекта. Без API/CLI imagegen и без заимствования рекламных изображений конкурента.

Исходные готовые PNG-мастеры уже содержат всю типографику и CTA. scripts/export-raster-campaigns.py выполняет только пропорциональное уменьшение, техническое продолжение фоновых крайних пикселей и оптимизированный экспорт в WebP; он не рисует отдельно текст, товар, кнопки или рекламные эффекты. Важная композиция при экспорте не искажается.

Габариты файлов экспортированы с запасом для Retina:
- главный слайд: 2752×416, центральный макет до 552×368;
- горизонтальная вставка: 2784×320, центральный макет до 480×320;
- акция: 1440×902, центральный портретный макет до 480×720;
- услуга: 906×432.

Полный набор промптов, источники PNG и записи о корректировках: artifacts/banner-review-v22/generation.json. Публичный manifest.json содержит только размеры, безопасные области и размер файлов, без локальных путей к исходникам.

## Референс

Повторная попытка открыть живую главную https://www.vseinstrumenti.ru/ показывает антибот-проверку. Полный визуальный аудит живой главной не заявляется. Ранее просмотрены доступные креативы и медиакит. У одного актуального рекламного файла CDN дополнительно проверен HTTP Content-Type: image/jpeg. Формат не определялся по внешнему виду.

## Проверки

320, 360, 375, 390, 430, 768, 1024, 1280, 1440, 1920 px:
- размеры рекламных контейнеров совпадают с предыдущей согласованной геометрией;
- одинаковые src на всех разрешениях, один растровый файл на баннер;
- у каждой рекламной ссылки единственный дочерний элемент img;
- для всех изображений computed object-fit = cover, пропорции не искажаются;
- безопасная область целиком попадает в видимый контейнер, обрезаются только внешние фоновые поля;
- горизонтального переполнения нет;
- геометрия измеренных согласованных элементов не изменилась;
- свайп и автопрокрутка работают;
- ошибок JavaScript нет.
