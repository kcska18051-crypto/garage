# Формы стоимости подбора эмалей и обращений по ремонту

## Реализованный объём

- `/services/paint-matching/`, `/automotive/`, `/polyurethane/`: действие и форма «Узнать стоимость». Ровно пять пользовательских полей: Имя*, Телефон*, Марка авто, Код краски, Комментарий. Обязательны только имя и телефон; остальные можно оставить пустыми.
- Общий раздел сохраняет `itemId=paint-matching`, название «Подбор автоэмали». Подразделы сохраняют `paint-automotive` / `paint-polyurethane` и собственные названия. Произвольная подуслуга на родителе не назначается, автоматический расчёт цены не обещается.
- В `/services/service-center/` пять направлений с собственными ID и формами: ремонт компрессоров, гайковёрта, болгарки, полировальной машинки, аппарата высокого давления. Модель/неисправность и необязательное фото остаются в прежней ремонтной форме; поля краски в неё не добавляются.
- У компрессоров сохранены существующая категория и винтовой/поршневой/дизельный подразделы. У остальных четырёх направлений только кнопки обращения на существующей странице, новых детальных маршрутов нет.
- Создаётся одна локальная демозаявка с точным ID/названием услуги; CTA открывает её точную деталь ЛК. Код краски и остальные поля видны в истории после reload. Реальных отправок, записи, платежей и расчёта стоимости нет.

## Данные и совместимость

Поле `paintCode` добавлено необязательным в существующую схему v1 (строка до200символов). Старые записи без него читаются без сброса; повреждённая история не перезаписывается. Новые данные сохраняют нормализованный контактный телефон с `+`, владелец сравнивается через прежнюю нормализацию. Правила подтверждения телефона, изоляция чужого номера, исправление старой ошибочной привязки после подтверждения и выход из аккаунта сохранены. Исторические фикстуры не удаляются.

## Границы

Это ограниченная доработка существующего сценария услуг. Другие страницы/корзина/промокод не меняются. Новые подробные страницы ремонта и напоминания не создаются. Пользовательские окна и данные сохраняются, собственные браузеры закрываются в finally. Публикация — явным списком файлов через API с expected-SHA, без force и blanket push грязной рабочей копии.
