# Закреплённые фильтры общей выдачи

Согласованная правка пользователя: на `/catalog/compressor-equipment/screw-compressors/receiver/` фильтры должны оставаться доступны при прокрутке страницы. Не менять меню каталога; mobile drawer сохранить.

## Реализация

- Причина: общий `.catalog-listing__sidebar` имел `position: static`.
- Общий `ProductListing`: sidebar `position: sticky`, `align-self:start`, `min-height:0`, без вырывания из grid. Границы — родитель `.catalog-listing__layout`, поэтому колонка останавливается до SEO/footer.
- Высота ограничена доступным viewport (`vh` / `dvh`), верхний/нижний отступы. Прокручивается только внутренняя область параметров, есть keyboard focus и `overscroll-behavior-y:contain`. Сброс вынесен из скролл-области и постоянно доступен.
- Верхний отступ учитывает реальную нижнюю границу закреплённой desktop-шапки. `usePinnedHeaderHeight` измеряет именно fixed-строку, не flow-spacer; реагирует на ResizeObserver, переключение full/compact и resize. Подписки и CSS-переменная очищаются.
- Desktop-применение остаётся немедленным, отдельная кнопка Apply не добавлена. Mobile ≤767px: sidebar скрыт, draft/apply drawer не менялся.
- Категория и бренд получают правку через общий компонент. Текущие акции настроены без sidebar (`showFilters=false`), эту конфигурацию не меняли; общий компонент поддерживает sticky при включённых фильтрах.

## Проверки и результаты

- RED: на точном receiver URL тест ожидал sticky, получил static.
- Контроль desktop: 1024/1440/1920/2560, mobile360/390. Проверяются page scroll, внутренний wheel/нижний checkbox/обновление результата/сброс, динамическая высота шапки, full/compact без сдвига grid, граница layout/footer, отсутствие overflow, mobile draft→apply.
- Для параметра после URL-навигации тест ожидает стабилизации React checked-state, затем отдельно проверяет изменение выдачи — не полагается на синхронную проверку внутри Playwright check().
- Локально пройдены **8 уникальных браузерных сценариев**: 6 receiver-размеров, общий sidebar категории/бренда и resize уже закреплённой страницы 1440→1024→390→1920. До/во время/после достижения границы layout проверено отсутствие перекрытия footer. Включён тест изменения реальной высоты компактной строки до 110px и обратного full/compact без сдвига grid.
- Дополнительный read-only review не нашёл блокирующих дефектов; его два замечания к покрытию (live resize и переход к footer) закрыты последним сценарием.
- Сборка успешна: 137 entry points; JS `index-DiKjrbRP.js`, CSS `index-Xulwrvh-.css`. Предупреждение Vite о размере chunk остаётся отдельной оптимизацией.
- Релевантные unit фильтров и шапки: **15/15**, в том числе сброс вне внутреннего scroll-region, сохранение счётчиков/сортировки и скрытие всей панели при `showFilters=false`.
- Долгий полный локальный unit-прогон без итогового вывода остановлен; успешным не объявляется. Полный набор должен завершиться в CI перед финальным подтверждением.
- CI / публичные результаты, commit SHA и ссылки заполняются после проверок и deploy.
