# Прямая заявка на аренду из товара Remeza

Согласованный путь: товар и выбранная модификация → сразу встроенная заявка → подтверждение → точная заявка в ЛК. Промежуточное информационное окно, категория и повторный выбор оборудования больше не нужны.

- Все три предложения Remeza поддерживают прямой вход. Изменение варианта в карточке передаёт фактически выбранный offer.id.
- URL: `/services/request?kind=rental&item=screw-compressor&product=<approved-offer-id>&from=/product/<approved-offer-id>`.
- Выбранное оборудование показано компактно: фото, название, модификация и артикул. Форма: контакты, город получения, даты, количество, комментарий. Контакты авторизованного клиента и текущий город подставляются; гостевой вход в форму не требует авторизации.
- Кнопка «Отправить заявку на аренду». Согласование наличия, тарифа и условий сохранено; гарантированная бронь и оплата не добавлялись.
- Заявка сохраняет offer.id, заголовок с модификацией, model с артикулом и город. Деталь в ЛК отображает модификацию/город и сохраняется после перезагрузки. Старые локальные записи без города читаются как раньше.
- Корзина покупки не изменяется. Сохранены защита от двойной отправки, принадлежность по подтверждённому телефону и сценарии других услуг.
- Параметры URL разрешаются только по существующим предложениям Remeza. Произвольный product не подставляет чужие данные и не создаёт внешнюю ссылку возврата.

Проверки перед публикацией: production build; 28 связанных unit-тестов (включая три модификации, сохранение города/артикула, перезагрузку и отсутствие изменений корзины); 3 новых браузерных сценария на 1440/390 px и для гостя; 7 существующих браузерных сценариев услуг. Итоговый полный unit-прогон и публикация выполняются GitHub Actions. Скриншоты production preview просмотрены; компактная карточка оборудования, привычная двухколоночная форма на десктопе, без переполнения на телефоне.
