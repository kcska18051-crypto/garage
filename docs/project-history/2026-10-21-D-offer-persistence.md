# Доработка D: выбор предложения после reload

Независимая проверка `7f26541` подтвердила A/B/C/E, но вернула D: UI-переключение на 220 В не изменяло адрес, reload восстанавливал базовые 380 В / 7,5 кВт / GR-0001. Проверка прямой variant-страницы не покрывала этот сценарий. Пакет не считается полностью принятым.

## Причина и исправление

`ProductDetailPage` хранил offer/selections только в React state. Теперь при выборе варианта обновляется query `variant=<offer ID>` через React Router с `replace:true`. Единственный источник выбранного offer — валидный query, затем исходный offer прямого PDP, затем default. Локальной дублирующей копии выбранного offer больше нет.

- Остальные query-параметры и hash сохраняются.
- Выбор не добавляет лишние записи истории, не сбрасывает прокрутку и количество.
- Back/Forward читают актуальный вариант из адреса. Прямые отдельные URL вариантов продолжают работать.
- Неизвестный query offer не создаёт новый SKU, используется допустимое исходное предложение.
- Корзина, КП, gallery/mobile purchase, опции и share получают один и тот же восстановленный offer.

## Локальная проверка

- Новый `e2e/offer-persistence.spec.ts`: сначала RED — в URL нет `variant`, затем GREEN.
- 360/390/1440/1920: базовый PDP → UI 220 В → reload → 169000 / GR-220-55 → своя строка корзины. Аналогично 380 В / 5,5 кВт / 176500 / GR-380-55 и 380 В / 7,5 кВт / 185000 / GR-0001.
- Сохранение `campaign=demo#characteristics`, позиция якоря после reload, возврат Back в каталог и Forward на выбранный PDP, отдельный прямой URL 220 В, неизвестное значение query, отсутствие overflow — PASS.
- Вместе с регрессией PDP/share/опций — **15/15 E2E**. Полный локальный unit: **234/234, 45 файлов**, exit 0, 199,72 секунды. Итог полного прогона получен с задержкой вывода; успешное завершение подтверждено кодом 0, не предположением.
- Сборка GitHub Pages успешна, 137 маршрутов, JS `index-Ds-ItYwX.js`. Предупреждение о chunk >500KB остаётся.
- AboutPage.tsx/CSS не менялись, исходные blob hash сохранены.

## Ограничения

Дублирующийся демонстрационный артикул GR-0001 у домкрата и компрессора сохранён и обозначен: товары имеют разные стабильные ID. Массовое переименование без плана не выполнялось. Все цены/характеристики — демоданные. Меню каталога и открытый охват акций не входят в эту доработку.
