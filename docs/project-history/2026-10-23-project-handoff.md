## Сегодняшняя задача и решения

Пользователь поручила добавить уведомление cookie, юридические ссылки футера и отдельные согласия во всех существующих формах обратной связи. Прототип не должен содержать выдуманные юридические условия; реальные документы предоставляет клиент и утверждает юрист.

Три самостоятельных маршрута:
- `/privacy` — Политика конфиденциальности.
- `/user-agreement` — Пользовательское соглашение.
- `/personal-data-consent` — Согласие на обработку персональных данных.

У документов собственные H1/крошки, общие шапка/подвал, свободный доступ без авторизации. Тела пока пустые: допустимы только отметка о будущем тексте заказчика и демонстрационном статусе. Ссылки не ведут на доставку/404. Политика не заменяет отдельное согласие.

Формы: два независимых обязательных checkbox, оба сняты по умолчанию: «Даю согласие на обработку персональных данных» (отдельное согласие + доступ к политике), «Принимаю пользовательское соглашение». Для демонстрации оба обязательны по требованию клиента, не как универсальное предписание закона. Рекламное согласие отдельно и необязательно. Ссылки не отмечают checkbox, не отправляют форму и не теряют ввод. Cookie-выбор не подставляет согласия обращения; новые обращения не наследуют отметки предыдущих.

Cookie: один сквозной provider на любом первом прямом URL; после нажатия выбор сохраняется на origin браузера и не повторяется на переходах/reload. Через настройки в футере уведомление открывается снова. Хранилище с версией, ошибка storage не ломает приложение; новая существенная версия вызывает однократный повторный показ. Это не вечное/межустройственное согласие.

Окончательное пожелание пользователя в этом аналитическом чате: компактная белая скруглённая плашка, текст по центру, одна монохромная кнопка «Я согласен» ПОД текстом; убрать «Только необходимые», «Подробнее», заголовок деморежима и пояснения о неподключённых трекерах. Ранее предложенный двухкнопочный вариант отменён.

## Важное расхождение — сверить перед следующей правкой

При сохранении прочитан актуальный исходник `prototype/src/features/cookie/CookieBanner.tsx`: одна кнопка и центрирование реализованы, однако текст сейчас: «Мы используем файлы куки (cookie) для вашего удобства. Продолжая пользоваться сайтом, вы соглашаетесь с политикой использования куки (cookie).» и ссылка «Подробнее» на `/privacy`.

Репозиторная спецификация `docs/superpowers/specs/2026-10-23-cookie-legal-consents-design.md` также называет этот текст утверждённым. Это расходится с явным последним пожеланием в данном аналитическом чате убрать «Подробнее» и с внесённой здесь редакцией Google Doc (короткий нейтральный текст без ссылки). Возможны дополнительные указания пользователя в чате разработки; перед изменением проверить их, не объявлять одну из версий автоматически принятой. В рамках запроса «сохранить» код не изменялся. Зафиксирована фактическая реализация и расхождение, а не ложная готовность.

В коде `CookiePreferenceState.tsx`: ключ `garage-cookie-preference`, version 2, варианты `all`/`necessary`; новый одно-кнопочный UI создаёт `all`, старый `necessary` читается для совместимости. UI-нажатие, а не скролл/навигация, записывает выбор. Футер: «Настройки куки (cookie)».

## Требования к реальному программированию

В 1С-Битрикс: управляемые версии правовых документов и единые ссылки/компоненты. Сервер проверяет нужные согласия до заявки; раздельно фиксируются вид, версия текста, время, связь с обращением и доказательство действия в согласованном объёме. localStorage не заменяет юридическое доказательство. Не сохранять в cookie-записи контакты/пароли и не собирать IP «про запас».

До запуска юрист/оператор определяют реальные цели, основания, состав данных/cookie, сроки, обработчиков, локализацию, уведомления и механизм отзыва/отказа. Однокнопочный UI не объявляется универсально законным механизмом; при фактической аналитике/маркетинге нужна соответствующая правовая и техническая модель до подключения. Не подключать трекеры в рамках косметической правки. Пустые документы и демоформы не дают основание реального сбора данных.

Источники для согласования: ст. 9 ч. 1, 3 и ст. 18.1 ч. 2 закона №152-ФЗ. Юридическое заключение не выдавалось.
