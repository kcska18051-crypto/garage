## Запуск на другом компьютере

1. Клонировать репозиторий и переключиться на codex/homepage-prototype
2. В папке prototype выполнить npm ci
3. npm run build:pages
4. npm run preview -- --host 127.0.0.1 --port 4196 --base=/garage/
5. Открыть http://127.0.0.1:4196/garage/style-check/

Нужны Node.js22+ и npm. Для сайта Python не нужен. Производственный экспорт отдельных растров использует Python/Pillow; актуальный render-responsive-raster-campaigns.py читает переносимые пути из artifacts/banner-review-v24/production.json. Исторические JSON промптов могут содержать прежние абсолютные пути: соответствующие оригиналы есть в архиве source-images-20261030. Не запускать экспорт V22/V24 вслепую поверх последних V31/V36: сайт использует отдельные финальные наборы
