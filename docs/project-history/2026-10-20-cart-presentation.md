# Пакет 1–4: избранное и представление корзины

Согласован пользователем; начат **после** публикации и публичной проверки вкладок городов `0565078` (отчёт `bd5181b`). Не включает меню каталога или новое наполнение категорий.

## 1. Избранное

- Используется существующий компактный `ProductTile`, как в «Вы смотрели»: фото 4,4rem, уменьшенные отступы. Desktop — фиксированные адаптивные колонки 12,5rem, 4–5 по доступной ширине; два товара не растягиваются на весь контент. Mobile — читаемая сетка из двух карточек с отдельным рядом действий.
- Название, артикул, наличие, акция, старая/новая цена, удаление, добавление в корзину и счётчики сохранены. Sidebar не менялся.
- [Desktop](screenshots/cart-refresh/favorites-1920.png), [mobile](screenshots/cart-refresh/favorites-390.png).

## 2. Поделиться корзиной

- Отдельный `ShareCartDialog`: отступы 16–24px, label над input на всю ширину, `min-width:0`/box-sizing, длинная ссылка прокручивается внутри поля; действия разделены и на mobile идут вертикально.
- Описание: «Поделитесь выбранными товарами. Личные данные не передаются». Основное действие «Копировать ссылку», вторичное «Открыть общую корзину ↗».
- Успех/ошибка объявляются отдельно; при отказе API ссылка выделяется для ручного копирования. Readonly-поле не вызывает лишнюю мобильную клавиатуру. Native modal dialog, Escape, замыкание Tab и возврат фокуса.
- Кодек URL, валидация, количества и связи `optionParents` не изменялись. Пользователь не видит внутреннюю терминологию связей в описании окна.
- [Desktop](screenshots/cart-refresh/share-1920.png), [mobile](screenshots/cart-refresh/share-390.png).

## 3. «Может пригодиться»

- Горизонтальные миникарточки: маленькое фото-заглушка слева, название до двух строк, цена и кнопка с SVG-иконкой корзины и полным aria-label. Мягкий светлый фон без отдельной крупной обводки. Desktop — до трёх колонок, mobile — свайп только внутри ленты.
- Использованы исключительно уже существующие релевантные `relatedForCart`; новые товары ради заполнения не создавались, опции не смешиваются с сопуткой.
- Правило раскрытия сохранено: 1–2 строки открыты, при 3+ только верхняя по умолчанию, ручное раскрытие работает. Повторный SKU объединяется, количество/цена пересчитываются. Итоги, как прежде, относятся к отмеченным строкам; логика выбора новых строк не изменялась.
- [Desktop](screenshots/cart-refresh/accessories-1920.png), [mobile](screenshots/cart-refresh/accessories-390.png).

## 4. Предварительная доставка в корзине

- В summary **корзины** удалена вся строка «Доставка — Рассчитаем при оформлении», без замены обещаниями цены/даты. Отдельное уточнение о наличии/сроке для города сохранено.
- Выбор и реальные условия получения в checkout не менялись. Desktop summary виден на скриншоте пункта 3; отсутствие строки проверено на всех четырёх ширинах.

## Проверки

- Четыре новых регрессионных теста сначала воспроизвели замечания; после реализации релевантный unit-прогон: 33/33 (избранное, корзина/checkout, share/кодек/merge).
- Новый E2E: 4/4, ширины 360/390/1440/1920. Компактность и свободное место desktop, данные/удаление/счётчик избранного, 1/2/3 строки корзины и ручное раскрытие, добавление/объединение SKU и суммы выбранных строк, внутренний mobile-scroll и отсутствие document overflow.
- Окно: копирование/ошибка, выбранная ссылка, Escape/возврат фокуса, отступ между полем и действиями; длинная валидная ссылка с 32 SKU и количествами 999 не растягивает окно. Clipboard API в тестах моделировался: системный буфер пользователя не читался и не изменялся.
- Регрессия опций: 2/2 E2E desktop/mobile — две конфигурации основного товара, чистый и непустой получатель, связи/количество/суммы после share и reload. `build:pages` успешен; известное предупреждение общего JS chunk >500KB вне этой UX-задачи.
- Скриншоты desktop/mobile осмотрены; шесть файлов приложены в `screenshots/cart-refresh/`.
