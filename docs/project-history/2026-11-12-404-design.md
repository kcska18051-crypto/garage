# Страница 404

404 приведена к согласованному стилю: белый фон, Manrope, мягкий жёлтый акцент за кодом ошибки, стандартный заголовок, объяснение и подсказка о поиске. Основное действие «В каталог» тёплое, «На главную» контурное. Общие шапка и подвал сохранены.

Исходная обработка title, noindex/follow и восстановление метаданных при уходе не менялась. Неизвестный адрес остаётся в строке браузера, автоматического перенаправления нет. Существующие отсутствующие товары/разделы продолжают показывать общий компонент 404.

Проверены: 17 тестов неизвестных маршрутов/метаданных; сборка Pages с 404.html; компьютер, телефон 390px и экран 820px, переход в каталог и возврат назад. Переполнения нет.

Для просмотра оформления: /garage/404/ — намеренно отсутствующий адрес, использует штатный fallback GitHub Pages.
