# Интерактивный прототип «Гараж»

В этой папке хранится весь код и связанные материалы интерактивного прототипа интернет-магазина «Гараж».

## Принципы прототипа

- нейтральная айдентика без привязки к будущему брендбуку;
- серые геометрические плейсхолдеры вместо финальной графики;
- интерактивные переходы между прототипируемыми страницами и состояниями;
- самостоятельные адаптивные решения для десктопа, ноутбука, планшета и мобильного устройства;
- возможность развивать прототип в основу будущего дизайна и фронтенд-вёрстки.

Первый проектируемый модуль — адаптивная шапка сайта.

## Локальный запуск

```powershell
npm install
npm run dev
```

Проверки:

```powershell
npm run test:run
npm run build
npm run test:e2e
```

## Реализованные маршруты

Главная страница полностью интерактивна. Для проверки навигации доступны страницы-заглушки каталога, поиска, услуг, акций, брендов, новинок, товара, избранного, сравнения, корзины, профиля, магазинов, доставки и оплаты, компании, контактов, материалов и B2B-раздела. Неизвестный адрес открывает страницу 404.

## Контрольные разрешения

Визуальная проверка проводится на ширинах 1440, 1280, 1024, 768, 390 и 360 пикселей. Скриншоты локальной проверки сохраняются в `artifacts/` и не входят в исходный код.
