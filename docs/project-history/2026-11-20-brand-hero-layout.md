# 20.11.2026 — компоновка шапки Remeza

По уточнению пользователя фото компрессора убрано из шапки полностью, включая десктоп. Справа на его месте расположен логотип Remeza, ниже — кнопка сертификата. На мобильном логотип/сертификат идут единой группой над текстом.

Слева заголовок, короткий вводный абзац и несколько абзацев рыбы, скрытых по умолчанию. Кнопка «Развернуть описание бренда / Свернуть описание бренда» показывает механику на десктопе и мобильном. Нижний ранее согласованный раздел о бренде сохранён.

Проверки: production build; 3 unit-теста страницы; 3 браузерных сценария 1440/390/320 — расположение логотипа/сертификата, отсутствие фото компрессора в hero, раскрытие/сворачивание, окно сертификата и отсутствие горизонтального переполнения. Десктопный скриншот просмотрен; мобильный locator-снимок содержит перекрытие sticky-шапкой из-за автоматической прокрутки при снимке, геометрия проверена до прокрутки.
