Меню каталога не начинать; принятый охват акций не блокер.

## Цель и границы

Современные компактные страницы в текущем нейтральном стиле, общий контейнер/шапка/подвал, desktop+mobile. Данных клиента нет: ВСЁ наполнение, изображения, оборудование, тарифы и условия явно демонстрационные. Без выдуманных реальных цен, сроков, гарантий, наличия, брони и дилерских обещаний. Не добавлять оплату, реальный календарь доступности, реальную отправку, историю обращений ЛК или хранение персональных данных.

## Структура и стабильные URL

- `/services`: три направления — «Сервисный центр по ремонту», «Подбор автоэмали», «Аренда оборудования и инструментов».
- `/services/service-center`: содержательная страница направления с переходом к категории.
- `/services/service-center/compressor-repair`: «Ремонт компрессоров», три дочерние деталки.
- `/services/service-center/compressor-repair/screw`: «Ремонт винтовых компрессоров».
- `/services/service-center/compressor-repair/piston`: «Ремонт поршневых компрессоров».
- `/services/service-center/compressor-repair/diesel`: «Ремонт дизельных компрессоров».
- `/services/paint-matching`: самостоятельная детальная страница, БЕЗ подкатегорий (заменяет раннюю идею 4–5 категорий).
- `/services/rental`: каталог демопозиций, не обычная товарная корзина.
- `/services/rental/hydraulic-jack`, `/services/rental/tool-set`, `/services/rental/piston-compressor`: отдельные деталки трёх имеющихся примеров прототипа.
- Старая `/services/workshop` — совместимый переход на общий список услуг, НЕ четвёртое направление. Старую hero-ссылку обновить на существующее направление ремонта.

Ремонтные страницы: рыбное описание, место фото, примеры работ, порядок обращения, стоимость/сроки «Уточняются», CTA «Оставить заявку». Промежуточные страницы содержательные, крошки и возврат на уровни понятны.

Подбор автоэмали: описание, место фото, этапы обращения, CTA и форма; без обещания точного совпадения цвета, сроков/цен/гарантии.

Аренда: 3 явно демонстрационные позиции на основе существующих product-1 (домкрат), product-2 (набор), product-4 (поршневой компрессор). Краткие параметры — только имеющиеся название/артикул/описание примера, неданные свойства помечаются «Уточняются». Ни одна цена покупки не превращается в тариф аренды. Каталог→деталка каждой позиции→заявка; тариф, залог, условия «Уточняются».

## Заявки

Общий доступный адаптивный диалог, закрытие кнопкой/Escape/фон, focus trap и возврат фокуса, блокировка фона/скролла; mobile не перекрывается нижней навигацией.

- Ремонт: имя, телефон, модель оборудования, описание неисправности — обязательны; фото необязательно. Фото локальное, одно JPEG/PNG/WebP до 5 МиБ, предпросмотр/удаление/очистка input, понятная ошибка типа/размера. Нет серверной загрузки.
- Автоэмаль: имя, телефон, автомобиль, комментарий — обязательны. Без дополнительных подкатегорий или техобещаний.
- Аренда: выбранная позиция явно передана в форму; даты начала/окончания обязательны, прошлые даты запрещены, окончание не раньше начала (равенство разрешено); количество — целое положительное; имя/телефон обязательны, комментарий необязателен. Без вычисления ложной итоговой цены.
- Телефон: 10–15 цифр после удаления допустимых разделителей; не принимать произвольный текст. Ошибки полей связаны через aria-invalid/aria-describedby, при ошибке фокус на первое поле.
- Результат: локальный номер `DEMO-...`, явная демонстрация без реальной отправки. Для аренды текст «Заявка на аренду отправлена» сопровождается пометкой, что это демонстрация, не бронь и не изменение доступности. В ЛК ничего не добавляется, корзина не меняется.
- Персональные данные и фото живут только в памяти формы, object URL освобождается; localStorage с ними не создаётся.

## Приёмка

Все уровни ремонта/3 деталки, самостоятельный подбор автоэмали, каталог и каждая деталка аренды. Валидные/ошибочные формы, фото (тип/размер/preview/remove), даты/количество, demo-успех и номер, Escape/focus, отсутствие изменения корзины/ЛК. Ширины 360/390/1024/1440/1920/2560 без document overflow, компактные изображения, удобные CTA.

Все новые URL включить в общий manifest статических входов; HTTP200 с/без slash и reload. Сборка, CI, публичная проверка и визуальный осмотр desktop/mobile, скриншоты/отчёт/SHA. После своей проверки закрыть браузер для независимой приёмки.
